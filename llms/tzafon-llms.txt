# Lightcone

> Lightcone by Tzafon is the computer-use API: cloud browsers and desktops operated by AI. Describe work in plain language and Northstar — a vision-language model trained to operate computers — does it. Automate apps that have no API.

## Getting started

- [Introduction](https://docs.lightcone.ai/): Overview of Lightcone and navigation to all documentation
- [Quickstart](https://docs.lightcone.ai/guides/quickstart): Run your first task in under 5 minutes
- [Authentication](https://docs.lightcone.ai/guides/authentication): Get your API key and configure the SDK
- [How Lightcone Works](https://docs.lightcone.ai/guides/how-lightcone-works): Architecture, the mental model (environment/computer/task/turn), models, vision vs DOM, glossary
- [Pricing](https://docs.lightcone.ai/guides/pricing): Token and compute pricing with worked examples
- [CLI](https://docs.lightcone.ai/guides/cli): Run tasks and drive computers from the terminal; wire up coding agents via MCP
